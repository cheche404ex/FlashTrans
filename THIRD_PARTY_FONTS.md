# Third-party fonts

FlashTrans bundles the following open-source fonts through `@fontsource-variable`:

- Inter, copyright 2016 The Inter Project Authors, SIL Open Font License 1.1.
- Cormorant Garamond, copyright Christian Thalmann, SIL Open Font License 1.1.
- Noto Sans SC and Noto Serif SC, copyright Google, SIL Open Font License 1.1.

The full license texts and font notices are kept in the corresponding package directories under `node_modules/@fontsource-variable/*/LICENSE` during development and are included in the generated application asset bundle. The fonts are used as bundled application assets, never fetched at runtime.
